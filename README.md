# text_summarizer
A Python tool that summarizes long text into 2-3 simple sentences using the Google Gemini API.
## Tech used
-Python
-Google Gemini API(google-generativeai)
-Google colab
## How to run
1.Open the notebook in Google colab
2.Add yor API Key in colab secrets with the name GEMINI_API_KEY
3.Run all cells
## What i learned
-Writing reusable functions
-Prompt design for summarization
-Keeping API keys safe using colab secrets
